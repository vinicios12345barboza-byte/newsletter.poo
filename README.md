# 📬 Newsletter com POO e Dark Mode

Sistema de cadastro de newsletter responsivo, contando com alternância de tema (Light/Dark Mode) nativa e arquitetura baseada em Programação Orientada a Objetos.

## 🧠 O que este projeto exercita?
Este projeto foi desenvolvido para consolidar meus estudos na reta final de JavaScript antes de migrar para frameworks. O grande foco foi aplicar os **pilares da Programação Orientada a Objetos (POO)**:
- **Abstração e Encapsulamento:** Utilização de classes (`GerenciadorUsuarios` e `Usuario`) para estruturar a aplicação, protegendo dados sensíveis com propriedades privadas (`#usuarios`).
- **Manipulação do DOM:** Gerenciamento de eventos de formulário e controle de estados de tema através de atributos de dados (`data-tema`) no HTML.
- **CSS Avançado:** Uso de Variáveis CSS (Custom Properties) para gerenciar o design do modo escuro de forma limpa e performática.

## 🛠️ Tecnologias Utilizadas
- HTML5 estruturado
- CSS3 com variáveis nativas e Flexbox/Grid
- JavaScript Moderno (ES6+) com Classes
